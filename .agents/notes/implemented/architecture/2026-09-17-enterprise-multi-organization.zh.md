# 企业多组织租户机制

[English](2026-09-17-enterprise-multi-organization.md) | 中文

SUNFLECK 将配置的企业组织视为平台组织，并允许该组织的管理员引导创建其他组织。一次引导操作会在同一身份仓储事务内写入组织、首位已启用管理员、单向密码校验值与管理员角色。租户管理员不能创建或列出其他组织。

本地登录按组织内用户名查询，并在同一组织内签发浏览器 Session。SSO 映射沿用已验证的组织；如果既有外部身份的映射组织发生变化，登录会被拒绝。`/auth/status` 分别公开当前组织、默认平台组织，以及当前主体是否为平台管理员。

组织内读写只从认证主体取得 `orgId`。新受管 Workspace 位于 `organizations/<org-hash>/users|departments` 下；已有授权继续使用其持久化路径。员工、能力、团队、记忆、渠道、Workspace、Session、策略和审计仓储继续执行组织条件。

模型运行时、Credential 服务和开发检查属于 Host 全局服务。只有平台组织管理员可以管理它们。租户管理员会收到 `organization-mismatch`，因此组织管理员角色不会转换为 Host 权限。

该边界不会自动隔离外置插件拥有的存储。一个文档知识插件只有在自己的数据库与 HTTP 操作中携带并校验认证组织后，其内容才适合在同一 Host 的多个租户之间安全使用。
