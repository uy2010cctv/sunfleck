# Agent Note: Agent 工作方式与数字员工组合

Status: implemented

[English](2026-09-25-agent-mode-and-employee-composition.md) | 中文

## 问题

把已发布员工选为 Session 的 Agent Preset 会替换用户选好的工作方式。员工记忆和自学习也从 preset 字段推断员工身份，但该字段应描述工具与工作风格。先前的[员工归属决策](2026-09-25-digital-employee-and-agent-mode-ownership.zh.md)确定了独立管理入口，却没有拆开运行时的两项选择。

## 决策

Session 保留 Agent Preset 作为基本工作方式。首轮对话前，有权限的用户可以在同一工作区选择已发布数字员工。必需的 Session 事件独立记录员工身份、不可变发布版本、组织和所有者，不随 preset 改变。员工提示词挂载在 Agent 作用域，仅覆盖工作方式中的身份提示词；工作方式的工具和其他提示词继续生效。恢复 Session 时校验记录的所有者和工作区，并加载同一发布版本。员工身份决定私有记忆与已学习能力上下文；发布版本固定已学习内容。工作区默认值只预选员工。目标优先的工作入口先以基本工作方式创建 Session，再绑定选定的员工版本。

以员工声明作为 preset 的旧 Session 继续通过历史注册表路径回放。员工声明仍出现在授权员工列表，但不进入通用工作方式选择和全局默认值。能力标签只描述职责，不授予可执行工具或数据权限。

## 曾考虑的方案

**为每个组合复制一份员工 preset。** 每种组合都要维护独立版本和回放身份，而且切换工作方式仍会替换员工运行版本，因此未采用。

**从当前 Agent Preset 推断员工。** 标准、PTC 和自定义工作方式都可以服务同一员工；切换工作方式必须保留员工身份，因此未采用。

## 结果

- 新 Session 有两项独立选择和一个不可变的员工发布版本引用。
- 首轮对话前切换工作方式会保留员工；切换员工会保留工作方式。
- 旧员工 preset Session 保留历史回放路径。新事件属于此版本识别的必需 Session 格式。
