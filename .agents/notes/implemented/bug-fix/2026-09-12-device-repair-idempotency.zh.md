# Agent Note：设备重连幂等性

状态：已实现

[English](2026-09-12-device-repair-idempotency.md) | 中文

## 问题

**连接此电脑** 按钮每次都分配新设备 ID。PostgreSQL 正确约束每个「组织、用户、公钥」只有一个身份，因此已绑定 Mac 重新连接时会触发唯一约束，前端只显示 `enterprise repository operation failed`。

## 决策

配对改为基于公钥唯一边界的单次、按所有者范围执行的原子 upsert。重复请求只刷新原设备的在线状态和心跳，保留其友好名称与平台，然后返回原设备 ID。签名心跳仍是独立操作，不能更改所有者或公钥。

## 考虑过的替代方案

**设备在线时禁用按钮。** 浏览器刷新、本机 Agent 重装或 UI 投影过期时仍需要重连，不能只靠展示层维护身份语义。

**先读取再插入。** 并发双击可能在读取和插入之间竞争，必须由数据库唯一边界原子完成幂等判定。

## 影响

重复点击和重试不再创建重复设备，也不再暴露通用 Repository 错误。公钥只在所属组织和用户范围内唯一，继续保持多用户隔离。
