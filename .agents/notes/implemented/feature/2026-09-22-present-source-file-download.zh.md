# Agent Note：下载已交付的源文件

状态：已实现

[English](2026-09-22-present-source-file-download.md) | 中文

## 问题

交付文件卡片可以在侧栏预览源文件，也可以请求服务 Host 的桌面打开文件。无桌面部署会禁用两个原生菜单操作，用户因而无法从浏览器保存生成的文档。

## 决策

[交付物插件](../../../../packages/client/ui-deliverables/README.zh.md)在每个交付文件菜单中增加“下载”。该操作通过当前查看的 Session、交付事件序号和原始文件索引访问认证 GET。Host 经当前查看的 Session 文件系统解析已记录声明，按有界字节窗口流式传输，并根据声明的 basename 设置附件文件名。下载不依赖 Host 桌面，在原生操作等待期间也保持可用。

路由在传输前记录源文件版本，并在读取每个字节窗口前核对。并发修改会使传输失败，避免返回混合多个版本的内容。点击前已经完成的编辑会反映在下载中；声明对应文件被删除、移动、不是普通文件或格式错误时失败，且不暴露 Host 路径。Session 日志仍只保存声明，不创建附件快照或回退副本。

## 考虑过的替代方案

**恢复不可变交付快照**可以保留历史内容，但也会恢复源文件交付设计已经拒绝的内容存储与保留义务。

**通过 Host 原生打开完成下载**不适用于无桌面服务器，也会在远程浏览器场景中把操作发送到错误设备。

**响应前读取完整文件**可以简化错误处理，但内存占用会随文件大小增长。有界读取保持稳定内存并允许大文件传输。

## 后果

下载内容代表点击下载时的源文件，而非声明时的内容。Session 导出仍不包含文件内容。浏览器认证和声明核验可防止通过修改查询参数下载任意路径。没有桌面元数据时文件卡片菜单仍可使用，只有默认应用和文件管理器操作会被禁用。

聚焦测试覆盖当前编辑内容、中文文件名、无桌面 Host、无效坐标、缺失源文件、菜单可用性、键盘导航以及下载与原生操作状态的独立性。录制的 Web 交付场景会下载源文件并核验最终文件名和内容。
