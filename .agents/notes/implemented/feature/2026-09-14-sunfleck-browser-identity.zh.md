# Agent Note: SUNFLECK 浏览器身份

Status: implemented

[English](2026-09-14-sunfleck-browser-identity.md) | 中文
## 问题

企业工作台需要在登录、导航、会话与浏览器安装中呈现统一且可辨识的产品身份，同时保留下层 DSH 执行系统。

## 决策

SUNFLECK 是浏览器产品身份。共享矢量标志、Phudu 字标、内嵌字体与成对的浅色／深色语义调色板遵循提供的身份资源。[品牌呈现](../../../../packages/client/ui-brand-official/README.zh.md) 保留官方 profile 注册与第三方槽位替换；默认会话首屏使用共享标志，不做鱼形变形。

后端包名、协议字段、持久化身份、运行时行为与提供方标签保留其技术含义。浏览器品牌不会重命名模型提供方，也不会创建另一套员工、Session、权限或审计权威。

## 考虑过的替代方案

**随产品一起重命名后端身份。** 这会把视觉身份调整扩展为运行时与持久化数据变更，却不改善界面。

**仅替换侧栏图形。** 登录、浏览器安装、会话首屏与操作颜色将呈现相互冲突的身份。

## 影响

前端具有统一身份，DSH 保留执行所有权与扩展行为。前端资源与字体许可证需要一同维护。验证覆盖共享标志、两种调色板、本地化标签、浏览器元数据以及官方 profile 与回退呈现；运行时与提供方名称不属于品牌替换范围。
