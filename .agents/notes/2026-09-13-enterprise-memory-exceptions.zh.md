# 企业记忆：自动激活与异常处理

[English](2026-09-13-enterprise-memory-exceptions.md) | 中文

用户诉求：每条企业记忆都要管理员批准过于繁琐。常规已确认的知识现在经 Agent 工具直接激活，不再按人配置自治策略。可选的 `needsConfirmation` 标志让不确定或冲突的表述保持提案状态。既有的主体身份、工作区范围、隐私校验与已下线记忆保护全部保留。管理员认证的手工创建在同一请求内激活，除非显式声明 needsConfirmation。

界面把强制定性的措辞替换为自动激活与异常确认，隐藏空的待处理通道，并支持对激活记忆的下线操作。异常确认不再要求模板化理由。既有已批准记忆保持不变。

验证：跨记忆上下文、HTTP 与治理界面共 49 个聚焦测试；定向 TypeScript 构建。
