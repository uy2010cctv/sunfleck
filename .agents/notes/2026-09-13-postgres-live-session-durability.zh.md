# PostgreSQL 活跃会话持久化修复

[English](2026-09-13-postgres-live-session-durability.md) | 中文

v0.1.5 的句柄适配器持久化了显式的发布前追加，却没有像 JSONL 提供方那样路由活跃会话事件。已完成的会话只留在内存中，重启后表现为空白。

修复注册了活跃事件、检查点与释放监听；保留失败的缓冲并等待关闭时的到达事件。关闭时会尝试所有句柄。修复前的回归测试以零恢复事件失败。16 个聚焦测试、包 TypeScript 构建与源码 lint 通过。已在真实 PostgreSQL + 原生 SessionStore 上验证关闭后的用户消息持久化与新提供方读取。

既有缺失的会话正文无法从仅含头信息的数据库行重建。保留源工作产物；不要根据截图编造会话历史。
