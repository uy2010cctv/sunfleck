# 频道正文替代轮次结束回执

[English](guide.md) | 中文

## 变更

频道员工在已完成的原生轮次内成功提交 `room_post` 时，Host 使用该正文作为频道答复，跳过额外的助手结束回执。直接调用和嵌套 PTC 调用都检查实际持久化的发布记录。发布失败、轮次未成功结束或没有 `room_post` 时，仍保留原生答复。群聊答复保持现有行为。原生 Session 消息和已有签名房间事件继续存储。

该轮交付文件通过 `replySourceSeq` 关联到最后一条成功发布的正文，包括在正文发布后声明的文件。

## 迁移

1. 频道事件页消费者应把已发布正文作为员工答复，无需等待第二条结束消息。
2. 使用返回的 `replySourceSeq` 关联交付文件；它可能指向原生 `room_post` 调用，而非最后一条助手消息。
3. 确认已完成且正文提交成功的频道轮次只出现一条正文及其文件，发布失败时仍可看到原生答复。参见[房间 API 参考](../../../../packages/api/enterprise-controller/README.zh.md)。
