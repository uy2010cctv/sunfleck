# 录音卡片 v0.13 用户自助绑定记录

时间：2026-09-21。

## 用户流程

当前登录用户在 SUNFLECK“我的设备”点击“绑定录音卡”，获得十分钟有效的六位数字。用户在 Android 录音中继 App 输入该数字；App 提交录音卡 SN 和 Android Keystore 中继公钥，不提交组织或用户 id。DSH 从一次性码解析所有者，签发录音卡专属凭据；App 保存新凭据并立即唤醒积压上传。

## 服务端实现

- Device Plane 增加一次性录音卡绑定挑战与录音卡设备类型；挑战只能消费一次，错误码不会消费，过期码失败。
- 同一用户重复绑定同一录音卡保持幂等；仍归其他用户所有的录音卡返回冲突。
- PostgreSQL schema 版本更新为 20，增加录音卡挑战和设备表；录音卡认证记录与 Computer Use 电脑记录分离。
- 企业 Device Remote 增加创建绑定码与列出当前用户录音卡接口。
- `/device-agent/v1/recorder/bind` 仅接受 47 网关持有的 bridge token，使用服务端 HMAC 保存录音卡序列号和设备凭据摘要。
- 47 网关增加 `/v1/bind_recorder`，绑定成功后原子写入专属凭据摘要，不保存明文凭据。
