# 录音记忆调取修复

[English](2026-09-22-memory-retrieval-repair.md) | 中文

时间：2026-09-22。

## 范围

本次修复以用户私有的索引录音时间轴替代每段一知识文档的调取方式，修正 worker 确认范围，重建历史加工代际，并把原文与加工记忆收敛为稳定会话文档。

## 行为

- JSONL 读取器推进持久文件字节游标，只解析新追加的完整行。
- 一个 WorkerState SQLite 连接拥有源游标、已解析段、入库确认和加工确认。
- `indexed_v1` 把早期成功入库记录重放一次到新 DSH 录音索引。
- `processed_v2` 按最旧优先重新加工早期账本；成功只标记实际以 `isNew` 进入请求的 ID。
- DSH 以组织/用户/稳定 ID 保存录音段，并建立所有者-时间和所有者-词元索引。
- 最近查询在一次工具调用中返回排序命中、最多 120 秒有界相邻上下文、稳定会话摘要、加工记忆和证据 ID。
- 加工为每个录音会话幂等更新一篇原文和一篇记忆文档。空提取是账本状态，不是文档。
- Android VAD 把 5 秒视为目标，等待 160 ms 微停顿，并以 8 秒为硬上限。

## 验证

- Worker 回归覆盖积压确认、追加游标、一次性索引重放、上下文、隔离和连接释放。
- Knowledge 测试覆盖稳定 ID 冲突、会话分组、索引主题排序、相邻上下文、稳定记忆幂等更新、索引入库回读、稳定文档 ID 和空加工状态。
- 10,000 段 built-JavaScript 基准的 20 次预热主题+相邻上下文查询中位数为 51.523 ms，P95 为 54.713 ms；不包括构建、模型推理和传输。
- Android 测试覆盖 5 秒目标后自然停顿以及 8 秒连续语音硬切。
