# 统一会话详情管理计划

[English](2026-09-29-room-details-management.md) | 中文

> **执行要求：** 使用 superpowers:subagent-driven-development 按任务实施。

**目标：** 为群聊与频道提供一致且可用的改名、成员管理、离开及归档操作，并校验当前成员和管理员权限。

**架构：** 共用详情组件使用现有基础组件和控制器。受保护的成员候选接口只返回有工作区访问权的人类成员和可执行的已发布员工。管理员可编辑名称及公告、增删成员并归档；其他成员可离开。确认及选择使用共享 Modal，保留异步状态和选择。工作流及决策保留频道专属区块。

## 服务端

- [ ] 群聊及频道生命周期和权限测试先失败后通过；离开成功后不再读取已失去权限的详情。
- [ ] 改名、公告、成员及归档校验当前会话管理员；离开只移除本人；保留管理员和归档内容。
- [ ] 保护成员候选和频道当值设置；移除员工时保持当值名册一致。
- [ ] 对合成群聊及频道执行真实源码 profile HTTP 生命周期、权限撤销及普通成员拒绝测试，更新所属文档。

## 客户端

- [ ] 共用详情替代重复的群聊表单，包含基本信息、人类成员、数字员工和结束操作。
- [ ] 单一可搜索多选弹窗过滤已有成员；加载、空列表、错误及重试分开呈现。
- [ ] 编辑失败保留草稿；移除、离开及归档使用共享 Modal 确认，等待期间禁用操作。
- [ ] 频道具有同样的管理操作和明确的当值选择；保留工作流及决策。
- [ ] 文案由语言字典管理，CSS 使用局部主题变量；测试会话类型、权限、确认、重试及弹窗关闭。

## 交付

- [ ] 先规格后质量审查，执行聚焦测试、类型检查、lint、文档校验及干净构建。
- [ ] 校验发布包并保留回滚；真实浏览器检查桌面和窄屏操作区，不修改真实成员或解散真实会话。
